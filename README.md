# محاكي مهمة B01

لعبة محاكاة للبوث: مركبة B01 السطحية تمسح المنطقة بالمسح الشبكي بتمريرتين، ترصد هدفًا مشتبهًا في عمود الماء، والزائر يقرر بحزمة التسليم المفسَّرة.

جميع البيانات في اللعبة بيانات محاكاة.

**التجربة على الويب:** https://moalqrnixd20000-design.github.io/b01-sim/

## طريقة اللعب
- **وضع العرض:** إذا ما أحد يلعب، تمسح B01 لحالها. أي ضغطة أو لمسة تفتح الإحاطة.
- **مدة المهمة:** تختارها في الإحاطة.
  - «حتى يكتمل المسح»: نحو 7 دقائق بالطيار الآلي.
  - «وقت أحدده»: يتسارع الزمن حتى يكتمل المسح في الوقت المحدد.
- **القيادة:**
  - **الكمبيوتر:** الأسهم أو WASD للقيادة، ومسافة للطيار الآلي، وC للكاميرا (خلفية، جانبية، علوية).
  - **التابلت:** أزرار اللمس، التوجيه يسار والسرعة يمين.
- **الطيار الآلي:** يكمل التمريرتين بتغطية 100%، ويمر على الأهداف كلها.
- **الأهداف الأربعة:** نفس أهداف موقع المنصة:

  | الهدف | مستوى الخطر |
  |---|---|
  | لغم مربوط محتمل | خطر محتمل مرتفع |
  | حطام مرجّح | خطر محتمل |
  | جسم غير معروف | غير معروف، يحتاج تحققًا |
  | حياة بحرية | غير خطِر |

- **القرار:** عند كل رصد تفتح حزمة التسليم بثلاثة خيارات:
  - تسليم لفريق التحقق.
  - طلب تمريرة متقاطعة، فترصد المركبة الهدف من الاتجاه الثاني وترتفع الثقة.
  - غير خطِر، تابع المسح.
- **الخمول:** بعد 60 ثانية بدون حركة ترجع اللعبة لوضع العرض.

## التشغيل بدون إنترنت
Three.js موجودة داخل المشروع في `vendor/`. شغّل خادمًا محليًا من مجلد المشروع:

```
python -m http.server 8746
```

ثم افتح `http://localhost:8746` بملء الشاشة (F11).
